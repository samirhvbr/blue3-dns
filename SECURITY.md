# Security policy

> **Status:** `ACTIVE` · Blue3 DNS is a public documentation repository.

Report exposed credentials, private DNS data, or a security problem in the
repository's tooling privately to **samirhv@me.com**. Do not include secrets or
personal query logs in public issues or pull requests.

The current `master` branch is maintained. The repository does not operate a DNS
service; problems in NextDNS or Apple software should be reported through the
respective vendor's channels.

The project's publication rules and response process are in
[docs/security.md](docs/security.md).
