# Changelog

## 0.1.0 - Establish the public DNS reference project

Organize the supplied NextDNS material into an English (US) service guide, an
iPhone setup and rollback guide, and a proposed evaluation framework for Blue3.
Clarify free-quota behavior, the Business billing unit, privacy boundaries, and
the distinction between a documented feature and a measured deployment. Record
official sources checked on 2026-11-05.

Initialize the public repository from the repodocs skeleton with the MIT license,
versioned documentation, private security reporting, git hooks, and a release
workflow on GitHub-hosted runners. Generated device profiles and DNS capture
artifacts are excluded from publication. No resolver, mobile profile, provider
account, paid subscription, or production configuration is provisioned.

Validation covers local Markdown links, the mirrored agent instructions,
version/changelog consistency, JSON/YAML parsing, shell syntax, and commit-hook
acceptance/rejection. Device behavior and a Blue3 pilot remain unverified.
